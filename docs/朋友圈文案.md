## 版本三 · 技术向（适合发在技术圈 / V2EX / 掘金）

> 用 Node.js 写了一个「广东中考英语听说在线模拟考场」，零第三方依赖。
>
> 几个有点意思的技术点：
>
> 1️⃣ **AI 组卷 + 强制算术校准**
> 让模型按考纲出题，但模型算加法经常出错——所以总分一律由服务端重新按
> `朗读/6 + 听选/9 + 回答/6 + 转述/6 + 询问/3 = /30` 重算并夹取，保证永远自洽。
>
> 2️⃣ **两级降级，绝不让用户白等**
> 模型网关抖的时候：组卷失败 → 用内置示例卷补齐；评分失败 → 切「逐词比对 + 要点覆盖 + 声学指标」的本地规则评分，照样出 30 分报告，**而且不扣额度**（额度改成出报告成功后才扣）。
>
> 3️⃣ **波形不靠解码**
> 录音时顺手采集 RMS 电平序列，压缩成 150 点包络直接画 canvas。不用 decodeAudioData，不用 Web Audio 重采样，任何浏览器都能画，还能标出停顿位置。
>
> 4️⃣ **必须 SSE 流式**
> 网关对非流式请求有 30s 上游超时（直接 524），而长输出必然超时，所以所有 LLM 调用一律边收边拼。
>
> 5️⃣ **双 Cookie 会话隔离**
> `jmkt_session` 和 `jmkt_admin` 分开，你可以在用学生账号练题的同时开着后台，互不顶号（这个 bug 是实测时才发现的）。
>
