    费用与购买

    本站为个人开发的公益向练习工具，服务器与模型调用有实际成本，因此采用「免费试用 + 次数卡 / 月卡」的方式维持运转。

    购买卡密

    定价说明与来源

    怎么获得额度？

    1. 注册即送：新用户注册后自动获得免费体验次数，无需付费。
    2. 兑换码：向管理员索取兑换码，在「我的账户」页面输入即可兑换次卡次数或月卡天数。
    3. 次卡：按次计费，一次完整模拟（自动组卷 + 全程录音 + 30 分制 AI 评分报告）消耗 1 次。
    4. 月卡：有效期内不限次练习，适合考前冲刺。

    说明：广东省中考英语听说考试由各地市教育局统一组织，不向考生收取任何考试费用。 本站与任何教育行政部门、学校均无关联，收费仅为覆盖本站的服务器与 AI 接口成本。

    常见问题

    评分准不准？
    评分严格按官方「内容 / 准确性 / 流畅性」三维度定档，并由三路 AI 评委并行评分后合成 30 分总分，与真实考试同档位划分。可用于查漏补缺，但不等同于官方成绩。
    为什么需要麦克风权限？
    本站需要在本地录音用于评分与波形分析。音频仅用于当次评分，不会上传保存。

    IP 封禁

    被封禁的 IP 打开网站会直接看到「当前 IP 已被封禁」页。支持精确 IP、网段前缀（如 192.168.1.）或 CIDR（如 1.2.3.0/24）。

    IP 白名单

    白名单内的地址不受封禁、脚本自动防护与接口限流影响。建议把自己家的固定出口 IP 或 IPv6 网段加入，避免误伤。

    —

    脚本访问防护

    同一 IP 在统计窗口内以脚本（curl、Python、程序请求等）访问超过设定次数时，自动封禁该 IP。普通浏览器访问不计入。
